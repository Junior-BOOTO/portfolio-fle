## Approche pédagogique

Chaque projet privilégie une situation de communication, des rôles coopératifs, trois parcours de différenciation et des critères observables « Je peux… ». Les dossiers documentent aussi les supports et les productions finales.

## État des publications

- Index et documentations GitHub : publiés.
- Jeux HTML : présents dans plusieurs dossiers ; leur ouverture peut nécessiter un hébergement ou un téléchargement.
- PDF imprimables : créés dans ChatGPT, dépôt GitHub à finaliser.
- Site professionnel : intégration à effectuer.
