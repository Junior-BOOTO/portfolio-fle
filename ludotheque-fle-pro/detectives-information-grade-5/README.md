# Projet 22 — Les détectives de l'information

**LUDOTHÈQUE FLE PRO · Grade 5 · CECRL A2 · 45 minutes**  
Conception pédagogique : Junior BOOTO WABA.

## Ancrage dans le curriculum
Grade 5, trimestre 2, unité « Comprendre un événement et vérifier l'information », préparation d'un journal scolaire francophone.

## Mission
Des journalistes en herbe vérifient des annonces dans une école **entièrement fictive**. Ils distinguent fait vérifiable et opinion, cherchent une source, une date et des preuves, puis rédigent une conclusion prudente.

## Pack conçu
- PDF **8 pages** : fiche enseignant ; **12 cartes** ; **6 dossiers d'enquête** ; fiche apprenant ; trois parcours différenciés ; corrigé ; grille d'observation **/8**.
- [Jeu interactif HTML](./index.html) : six questions autocorrectives et une fiche de vérification rédigée dans le navigateur.

## Déroulement (45 min)
- **Ouverture : 8 min** — les élèves vont rappeler ce qu'est une opinion et formuler une première hypothèse.
- **Enquête : 30 min** — en groupes de 4 (lecteur, chercheur de source, secrétaire, rapporteur), les élèves vont examiner les cartes, demander des preuves, noter des incertitudes et produire une mini-rubrique.
- **Clôture : 7 min** — les élèves vont présenter une conclusion prudente et compléter « Je peux… ».

## Différenciation
- Soutien : 4 cartes + amorces de phrases.
- Guidé : 8 cartes + questions de vérification.
- Autonome : 12 cartes, comparaison des sources et conclusion nuancée.

## « Je peux… »
- Identifier une opinion.
- Chercher qui parle et quand.
- Demander une preuve.
- Dire « je ne peux pas encore confirmer ».

## Publication
README et jeu HTML publiés sur GitHub. Le PDF de 8 pages est disponible dans la conversation ChatGPT, mais **non encore déposé sur GitHub ni sur le site professionnel**. Tous les cas d'école sont inventés.
