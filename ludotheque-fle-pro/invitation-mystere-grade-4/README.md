# Projet 15 — Invitation mystère

**LUDOTHÈQUE FLE PRO · Grade 4 · A2 · 45 minutes**

Conception : Junior BOOTO WABA.

Jeu consacré aux invitations, aux réponses polies et à l'organisation d'une sortie culturelle, dans le prolongement des unités du premier trimestre du Grade 4.

Le pack PDF de huit pages comprend douze cartes de sorties fictives, six défis, fiches enseignant et apprenant, trois parcours différenciés, grille formative et corrigés.

**Déroulement** : ouverture (8 minutes) pour identifier jour, heure, lieu et activité ; enquête coopérative (30 minutes) en équipes de quatre avec négociation des disponibilités et rédaction d'une invitation ; clôture (7 minutes) avec dialogues et autoévaluation.

**Je peux** repérer les informations d'une invitation, proposer une sortie, accepter ou refuser poliment, rédiger une invitation complète.

**Publication** : documentation GitHub mise en ligne ; le PDF complet est téléchargeable dans la conversation de conception mais n'est pas encore hébergé sur GitHub ou sur le site web.
