# Projet 28 — Escape game : Le code de la francophonie

**LUDOTHÈQUE FLE PRO · Grade 5 · A2 · 45 minutes**  
Conception pédagogique originale : **Junior BOOTO WABA**.

## Mission
Une rédaction scolaire fictive a perdu son code. Les élèves coopèrent en équipes de 3 à 4 pour résoudre **six énigmes** sur les langues, les goûts, les faits et opinions, la vérification de sources, les droits et les responsabilités environnementales. Code final : **321333**.

## Ressources réalisées
- **PDF de 8 pages** : couverture, guide enseignant, six cartes-énigmes à découper, carnet de mission, trois parcours différenciés, corrigé et grille formative sur huit points.
- **[Escape game numérique](./index.html)** : six énigmes autocorrectives avec collecte des six chiffres.

## Déroulement
- Ouverture 8 minutes : rappel du lexique et annonce de la mission.
- Phase principale 30 minutes : lecture, justification de preuves et collaboration en équipes, avec rôles tournants de lecteur, enquêteur, médiateur, secrétaire.
- Clôture 7 minutes : vérification du code, engagement écocitoyen final et autoévaluation.

## Je peux…
Lire une information simple, différencier fait et opinion, donner une preuve, écouter mon équipe et proposer un engagement écologique.
