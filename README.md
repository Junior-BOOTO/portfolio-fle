## Lire les preuves avec leur contexte

Chaque projet précise son public, les objectifs et les ressources disponibles. « Conçu » ou « prototype » ne signifie pas « expérimenté » ; aucune amélioration chiffrée des apprentissages n’est revendiquée sans résultats documentés. Les quatre compétences sont évaluées séparément.

Les dossiers d’assistants publient une documentation et parfois un exemple de sortie. Leur présence sur GitHub ne constitue pas un accès au GPT dans ChatGPT.

## Utiliser et documenter

1. Ouvrir le projet et vérifier son public, son statut et les fichiers effectivement disponibles.
2. Adapter les aides et les supports au niveau des apprenants.
3. Consigner les observations de classe dans un espace approprié ; publier uniquement des exemples fictifs ou des contenus autorisés.
4. Vérifier les droits de chaque ressource avant réutilisation : aucune licence générale n’est actuellement définie.
