# Les reporters de la classe

Public : A1, primaire ou début du secondaire. Durée : 25 min. But : découvrir les goûts de plusieurs camarades, puis présenter deux informations fiables en français.

## Ouverture — 4 min, classe entière

Montrer un dessin de ballon et un livre. Demander « Tu aimes le football ? Tu aimes lire ? » ; accepter une première réponse brève, puis modéliser « Oui, j'aime… / Non, je n'aime pas… ». Annoncer le lien : nous allons utiliser ces expressions pour réaliser une enquête de reporters.

## Activité principale — 16 min

Les élèves vont interroger au moins trois camarades, noter leurs réponses et préparer deux phrases de compte rendu. Regroupement : échanges successifs en binômes dans la classe entière ; une seule question par rencontre avant de changer de partenaire. Pour une classe où le déplacement est difficile, organiser deux rangées de partenaires, dont une change de place, ou faire passer les cartes de rôles.

Règles : poser la question en français ; écouter la réponse avant de noter ; ne pas inventer d'information ; accepter qu'aucun camarade ne corresponde à un item. Le but est une enquête fiable, pas de remplir à tout prix toutes les cases. Un élève peut choisir un personnage fictif et annoncer « Je réponds pour mon personnage ».

L'enseignant modèle un échange avec un élève, distribue la fiche et observe trois indicateurs : question formulée, réponse comprise, trace fidèle. Le dictionnaire aide à vérifier le sens d'un loisir, sans remplacer l'échange. La fiche rejoint le portfolio.

Aide A1 : questions imprimées, dessins et réponses modèles visibles. Consolidation : poser la question sans lire toute la phrase. Extension A2 : ajouter « Pourquoi ? » ou « Quand ? », puis écrire une raison ou un moment. Aucun renseignement familial ou sensible n'est demandé.

## Fiche originale d'enquête

| Je cherche quelqu'un qui… | Ma question | Prénom ou code choisi | Réponse entendue |
|---|---|---|---|
| aime dessiner | Tu aimes dessiner ? | | |
| aime chanter | Tu aimes chanter ? | | |
| aime jouer au football | Tu aimes jouer au football ? | | |
| aime lire | Tu aimes lire ? | | |
| aime danser | Tu aimes danser ? | | |
| aime jouer aux jeux de société | Tu aimes jouer aux jeux de société ? | | |

Banque de réponses : « Oui, j'aime… », « Non, je n'aime pas… », « Tu peux répéter ? ».

Compte rendu : « … aime … . … n'aime pas … . » Dire « aucun résultat » lorsqu'aucune réponse positive n'a été obtenue, sans assimiler cette absence à un échec.

## Variante autonome — cartes de personnages fictifs

Distribuer une carte par élève si l'on préfère une enquête sur des personnages. Une réponse non indiquée se formule « Je ne sais pas ».

| Personnage | Aime | N'aime pas |
|---|---|---|
| Lina | dessiner, lire | danser |
| Sami | chanter, jouer au football | lire |
| Eva | danser, jouer aux jeux de société | chanter |
| Noa | lire, jouer au football | dessiner |

Corrigé de la variante : dessiner → Lina ; chanter → Sami ; football → Sami ou Noa ; lire → Lina ou Noa ; danser → Eva ; jeux de société → Eva. Dans l'enquête réelle, il n'existe pas de corrigé unique : la référence est la réponse du camarade.

## Clôture — 5 min, individuelle

Chaque élève pose une question à un partenaire et répond à une question, puis écrit deux phrases concordant avec ses notes. « Je peux poser une question, comprendre une réponse et transmettre deux informations. » Vérifier : question pertinente, réponse pertinente, deux informations fidèles. Réussite locale : les quatre éléments sont présents ; si un élément manque, proposer un nouvel échange guidé. L'enseignant observe l'oral sur plusieurs moments du jeu pour disposer d'une trace pour chacun.

Inspiration : mécanisme d'enquête des activités 1–3 du livre ; questions, personnages et protocole d'évaluation créés pour ce kit.
