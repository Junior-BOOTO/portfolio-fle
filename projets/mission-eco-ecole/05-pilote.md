# Mise en œuvre, collecte et amélioration

## Avant le pilote

Confirmer public et créneaux ; préparer les dessins CO et lexique ; imprimer les formes A/B ; vérifier que les dessins sont distincts ; prévoir le temps oral initial et final ; recueillir le diagnostic ; adapter l'étayage. Aucun résultat n'est disponible dans cette version.

## Journal de séance

Pour chaque séance, relever : date ; présents ; durée réelle ; activité réalisée ; aide utilisée ; difficulté observée ; preuve recueillie ; changement à apporter. Noter aussi les écarts au protocole, par exemple affiches visibles pendant une évaluation.

## Indicateurs et décisions

| Indicateur | Calcul ou observation | Décision proposée |
|---|---|---|
| Réussite par compétence | Nombre atteignant le seuil / nombre évalué | Si moins de 70 %, revoir la tâche et l'étayage avant un second pilote |
| Évolution individuelle | Score final moins score initial pour chaque compétence | Repérer les besoins de reprise ; ne pas attribuer automatiquement le gain au dispositif |
| Faisabilité | Minutes réellement utilisées / durée prévue | Si dépassement de plus de 10 min dans deux séances, réduire ou répartir les tâches |
| Usage des aides | Aide nécessaire en entraînement puis retrait possible | Simplifier ou renforcer les supports selon les observations |
| Participation | Chaque élève a écrit et présenté personnellement | Réorganiser les rôles si une production collective masque une non-participation |

Les seuils de régulation sont proposés pour le pilote et devront être ajustés. Comparer uniquement les élèves disposant des deux passations pour les gains. Indiquer l'effectif, les absences et les conditions. Une comparaison avant/après sans groupe de comparaison décrit une évolution ; elle ne démontre pas un effet causal.

## Données minimales

Le fichier CSV fourni est vide. Utiliser des codes tels que E01 dans le suivi interne. Aucun nom, photographie ou voix d'élève n'est nécessaire. Le dépôt public peut présenter des exemples fictifs explicitement identifiés ou des synthèses agrégées évitant l'identification dans les petits groupes. Conserver les traces individuelles dans le cadre scolaire approprié.
