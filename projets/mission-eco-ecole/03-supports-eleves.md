# Fiches élèves — à imprimer séparément

## Fiche 1 — Les mots de la mission

Dessine chaque élément dans une case. Cache les mots et demande à ton partenaire de retrouver le mot.

| un arbre | une fleur | l'eau |
|---|---|---|
| un papier | une bouteille | une poubelle |

Cartes à découper : ARBRE / FLEUR / EAU / PAPIER / BOUTEILLE / POUBELLE.

Pour l'association individuelle, l'enseignant prépare six dessins sans légende : arbre, fleur, goutte d'eau, morceau de papier, bouteille, poubelle. Utiliser les mêmes dessins de référence aux deux évaluations, dans un ordre différent. Vérifier leur reconnaissance en espagnol avant le diagnostic sans donner les mots français.

## Fiche 2 — Les gestes

Écoute la phrase. Choisis A ou B.

1. Je ferme le robinet. A : arrêter l'eau. B : laisser l'eau couler.
2. Je ramasse le papier. A : laisser le papier au sol. B : prendre le papier au sol.
3. Je protège la fleur. A : prendre soin de la fleur. B : écraser la fleur.
4. Je réutilise la feuille. A : écrire sur l'autre côté. B : jeter une feuille utilisable.

Ces explications servent à préparer les dessins : l'enseignant dessine les deux actions et cache les textes français lors des exercices d'écoute. Mots nouveaux : un robinet ; une feuille de papier.

## Fiche 3 — Lire une affiche

**Notre mission**

Dans notre école, nous protégeons la nature. Lina ferme le robinet. Pablo ramasse le papier. Sara protège la fleur. Nous réutilisons les feuilles.

1. Où se passe la mission ? À l'école / au cinéma.
2. Qui ferme le robinet ? Lina / Sara.
3. Que ramasse Pablo ? Le papier / la fleur.
4. Que réutilisons-nous ? Les feuilles / les arbres.

Souligne les mots qui t'aident. Corrigé enseignant : école ; Lina ; papier ; feuilles.

## Fiche 4 — Notre petite enquête

L'enseignant dessine au tableau : (1) un robinet qui coule sans utilisateur ; (2) un papier au sol ; (3) une feuille utilisée sur une seule face.

Observe. Choisis un geste pour chaque situation. Explique ton choix à ton groupe, avec des mots simples ou un dessin. Puis écris tes propres phrases.

Banque de mots : ferme / ramasse / réutilise / protège / le robinet / le papier / la feuille / la fleur / l'arbre.
