# Mission Éco-école | FLE Learning Design Lab

**Author: Junior BOOTO Waba — French language teacher**

An original instructional design prototype for beginner primary learners in Colombia. Learners understand simple environmental instructions, read short messages, write an awareness poster and present actions in French.

**Status:** designed prototype; classroom implementation and impact evaluation pending. No learner results are claimed. Six proposed 45-minute sessions for Grade 4, subject to diagnostic and school scheduling. A1 is the intended language level, not a certified assessment outcome.

## How to use

Read the design brief, prepare the student materials, administer the baseline, adapt the lesson support, then teach the six sessions. Record individual assessment evidence and revise the design after the pilot. Markdown files can be read directly on GitHub or printed from a Markdown editor. No installation or paid platform is required.

## Design rationale

Ardouin's analyse–design–implement–evaluate approach frames the training device; ADDIE structures production of learning materials. Observable objectives and individual assessment make the design reviewable. Collaborative posters provide a meaningful task, while individual checks distinguish personal progress from group output.
