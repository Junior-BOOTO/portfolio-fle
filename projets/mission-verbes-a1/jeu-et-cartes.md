# Le jeu prêt à reproduire

## Matériel et plateau

Dessiner une piste de douze cases en boucle sur A3 : 1 Transforme ; 2 Détective ; 3 En scène ; 4 Écoute ; répéter ces quatre catégories jusqu'à 12. Ajouter une flèche « Départ ». Découper les cartes par catégorie et constituer quatre piles. Garder les corrigés dans une feuille séparée ou au verso caché.

## Règles

Un élève lance le dé, avance, puis tire la carte de la catégorie. Le lecteur lit seulement la consigne ; le vérificateur conserve la réponse cachée. Le joueur répond, puis indique radical et terminaison pour une carte Transforme. Le vérificateur révèle la réponse et explique. Correct sans aide : 1 point ; après correction comprise : 0,5 point ; sans réponse comprise : 0 point. Si le tableau des terminaisons est consulté, le maximum est 0,5 point. Toute correction donne lieu à une nouvelle production du joueur.

Rôles tournants à chaque tour ; le joueur ne vérifie pas sa propre réponse. Une carte utilisée rejoint le dessous de la pile. Arrêter après trois tours par élève ou quinze minutes. But collectif : atteindre deux points par joueur en moyenne ; objectif provisoire de jeu à ajuster après le pilote. Aucun joueur n'est éliminé.

## Douze cartes — défis

| Carte | Catégorie | Consigne donnée au joueur |
|---|---|---|
| T1 | Transforme | Écris : nous + chanter. Indique le radical et la terminaison. |
| T2 | Transforme | Écris : vous + préparer + la fête. Indique le radical et la terminaison. |
| T3 | Transforme | Écris : elles + dessiner + une affiche. Indique le radical et la terminaison. |
| D1 | Détective | Corrige par écrit : « Tu joue avec ton ami. » Explique le changement. |
| D2 | Détective | Corrige par écrit : « Nous dansent ensemble. » Explique le changement. |
| D3 | Détective | Corrige par écrit : « Vous parle français. » Explique le changement. |
| S1 | En scène | Le lecteur montre le mot DANSER et mime l'action. Décris avec « elle ». |
| S2 | En scène | Le lecteur montre le mot DESSINER et mime l'action. Décris avec « nous ». |
| S3 | En scène | Le lecteur montre le mot CHANTER et mime l'action. Décris avec « tu ». |
| E1 | Écoute | Le lecteur dit deux fois « Ils jouent au football ». Écris le sujet et le verbe. |
| E2 | Écoute | Le lecteur dit deux fois « Tu chantes une chanson ». Écris le sujet et le verbe. |
| E3 | Écoute | Le lecteur dit deux fois « Nous préparons une fête ». Écris le sujet et le verbe. |

Pour les cartes En scène, préciser le sujet avant le mime ; ce sont des productions guidées. Une phrase plus longue est admise si elle reste correcte et correspond à l'action.

## Corrigés — réservés au vérificateur

| Carte | Réponse et explication |
|---|---|
| T1 | Nous chantons ; chant- + -ons. |
| T2 | Vous préparez la fête ; prépar- + -ez. |
| T3 | Elles dessinent une affiche ; dessin- + -ent. |
| D1 | Tu joues avec ton ami ; -es avec tu. |
| D2 | Nous dansons ensemble ; -ons avec nous. |
| D3 | Vous parlez français ; -ez avec vous. |
| S1 | Elle danse ; dans- + -e. |
| S2 | Nous dessinons ; dessin- + -ons. |
| S3 | Tu chantes ; chant- + -es. |
| E1 | Ils jouent ; jou- + -ent. Le sujet entendu permet de choisir l'orthographe. |
| E2 | Tu chantes ; chant- + -es. |
| E3 | Nous préparons ; prépar- + -ons. |

## Gabarit pour les créations des élèves

Numéro : … ; catégorie : … ; consigne : … ; réponse : … ; radical : … ; terminaison : … ; explication : … ; validation de l'enseignant : … .

Les cartes créées doivent utiliser les verbes réguliers retenus et une consigne sans ambiguïté. Ne pas remplacer une réponse grammaticale par un jugement sur la beauté du dessin ou la rapidité.
