# Fiches élèves

## Fiche 1 — Le code

Pour conjuguer un verbe régulier du premier groupe au présent, je retire -er et j'ajoute la terminaison du sujet.

| Sujet | Terminaison | Exemple |
|---|---|---|
| je | -e | je parle |
| tu | -es | tu parles |
| il / elle / on | -e | elle parle |
| nous | -ons | nous parlons |
| vous | -ez | vous parlez |
| ils / elles | -ent | ils parlent |

À l'oral, je ne prononce pas le -ent de « ils parlent ». J'écris la terminaison même si je ne l'entends pas. Ce tableau concerne les verbes réguliers travaillés dans ce jeu.

## Fiche 2 — Diagnostic

Complète sans tableau : je parl… ; tu chant… ; elle dans… ; nous jou… ; vous dessin… ; ils prépar… . L'enseignant utilise les réponses pour choisir les aides, puis donne la correction après la collecte.
