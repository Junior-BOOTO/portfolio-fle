# Évaluation individuelle — preuves et corrigés

La note ne dépend pas du score de partie. Sans tableau ni corrigé ; conserver et noter les aménagements d'accessibilité. Les tâches CO, CE et PE demandent environ dix minutes ; ajouter environ trente secondes d'oral par élève. Les seuils sont locaux, pas une certification CECRL.

## CO — 4 points

Avant la passation, préparer quatre lignes de trois dessins sans légende :

1. Une fille chante / danse / dessine.
2. Deux personnes jouent au football / chantent / dessinent.
3. Plusieurs personnes dessinent une affiche / jouent au football / dansent.
4. Un garçon danse / dessine / chante.

Lire deux fois chaque phrase, lentement, sans mime : 1 « Elle danse » ; 2 « Nous jouons au football » ; 3 « Ils dessinent une affiche » ; 4 « Il chante ». L'élève entoure un dessin par ligne. Corrigé : 1 deuxième ; 2 premier ; 3 premier ; 4 troisième. Un point par choix correct ; réussite à 3/4.

La CO évalue ici la compréhension de l'action, pas la connaissance d'une terminaison silencieuse. Les dessins sont à préparer avant l'utilisation.

## CE — 4 points

Lire : « Lina chante. Pablo et Sara dansent. Nous préparons la fête. Vous dessinez une affiche. »

1. Qui chante ? Lina / Pablo et Sara.
2. Qui danse ? Lina / Pablo et Sara.
3. Quel sujet accompagne préparons ? Nous / Vous.
4. Quel sujet accompagne dessinez ? Vous / Nous.

Corrigé : Lina ; Pablo et Sara ; Nous ; Vous. Un point par réponse, réussite à 3/4. Ne pas lire le texte à voix haute pendant cette tâche.

## PE — 10 points

A. Conjugue : je + jouer ; tu + dessiner ; elle + préparer ; nous + danser ; vous + chanter ; ils + parler. Un point par forme correcte, maximum six.

Corrigé : je joue ; tu dessines ; elle prépare ; nous dansons ; vous chantez ; ils parlent. Seuil grammatical : cinq formes sur six.

B. Écris deux phrases : l'une avec « nous », l'autre avec « elles ». Choisis deux verbes parmi chanter, jouer, dessiner. Pour chaque phrase : un point si sujet et forme sont correctement associés ; un point si l'action est compréhensible avec un complément cohérent. Maximum quatre. Exemples : « Nous chantons une chanson », « Elles dessinent une maison ». Accepter toute autre réponse respectant ces critères ; les erreurs mineures dans le complément sont admises si le sens reste clair.

Réussite PE proposée : ≥8/10, avec ≥5/6 dans A et deux messages compréhensibles dans B.

## PO — 4 points

Présenter deux dessins originaux, un de personnes qui chantent et un de personnes qui dansent. Demander : « Fais une phrase avec vous et chanter », puis « Fais une phrase avec nous et danser ». Un point par énoncé associant correctement sujet et forme ; un point par message intelligible. Réponses attendues : « Vous chantez », « Nous dansons », avec compléments possibles.

Réussite PO : 3/4 avec deux messages compréhensibles. L'oral ne permet pas à lui seul de distinguer toutes les terminaisons écrites ; les sujets nous et vous rendent ici la différence audible.

## Retour et remédiation

Conserver quatre résultats distincts ; ne pas additionner automatiquement ces échelles différentes en une note globale. Si erreurs je/tu/ils : tri écrit de terminaisons ; si nous/vous : cartes sujet–verbe ; si compréhension faible : association phrase–action ; si phrases incomplètes : reconstruction sujet–verbe–complément puis nouvelle production individuelle.

Retour : « Tu réussis à… Pour progresser, travaille… Ta prochaine tentative sera… ». Une absence est une donnée manquante. Conserver la grille et la production dans le portfolio.
