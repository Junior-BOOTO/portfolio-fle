# Mission Verbes — Le défi des six personnages

Auteur : Junior BOOTO Waba. Version 0.1, prototype pédagogique à expérimenter.

Projet FLE A1 : apprendre à utiliser les verbes réguliers du premier groupe au présent en créant et en jouant à un jeu de plateau. Public : primaire ou début du secondaire, à adapter après diagnostic. Trois séances de 45 minutes ; prévoir un créneau oral supplémentaire selon l'effectif.

## Le défi

Six personnages — je, tu, il/elle, nous, vous, ils/elles — préparent une fête. Les joueurs réalisent des missions linguistiques pour les aider. Chaque groupe de trois ou quatre produit un plateau et douze cartes validées par l'enseignant, puis échange son jeu avec un autre groupe.

Lire le guide, préparer les cartes et le plateau, puis utiliser le jeu fourni comme modèle. Les cartes doivent être découpées en séparant défis et réponses ; le vérificateur garde les réponses hors de la vue du joueur. Les dessins demandés sont réalisés par l'enseignant ou les élèves. Aucun logiciel ni achat nécessaire.

Conjugaisons cibles : parler, chanter, danser, dessiner, jouer, préparer. Terminaisons : -e, -es, -e, -ons, -ez, -ent. Le verbe aller est exclu : il appartient au troisième groupe. Les particularités de manger, commencer ou appeler sont réservées à un parcours ultérieur.

Les formes parle, parles, parlent se prononcent de la même manière : l'oral vérifie la communication ; l'écrit vérifie aussi les terminaisons. Le score de partie ne constitue pas la note individuelle.
