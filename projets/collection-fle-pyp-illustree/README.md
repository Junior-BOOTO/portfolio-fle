# Collection FLE PYP illustrée — Grades 1 à 5

30 unités • 60 fiches (30 apprenant et 30 enseignant) • 10 recueils annuels.

Les recueils annuels rassemblent les mêmes fiches : choisir le format adapté à la préparation. Les guides enseignants incluent les corrigés.
