Enregistrer, réécouter et conserver une prise. Aucun envoi réseau, aucune analyse automatique et aucune sauvegarde après fermeture.

Prêt. Téléchargez chaque prise que vous souhaitez conserver.

Mode d’emploi et limites

Ouvrez ce fichier dans un navigateur compatible. Le navigateur vous demandera l’accès au microphone. Si le micro est indisponible, utilisez l’enregistreur de votre appareil. Après la prise, écoutez puis téléchargez le fichier. Le format dépend du navigateur.

La prise s’arrête après deux minutes maximum. Les scripts ne sont pas enregistrés automatiquement. Le nom du fichier contient seulement le code, la version et la date. Conservez les voix d’élèves dans l’espace institutionnel prévu, jamais dans un dépôt public sans cadre de diffusion validé.

V0 : premier message. V1 : message travaillé. V2 : message nouveau. Les prises permettent une réflexion avec l’enseignant ; le logiciel ne calcule aucune note et ne fournit aucun modèle vocal.

Conçu en novembre 2026. Compatibilité microphone à vérifier sur votre appareil avant la séance.
