# Empreintes sonores

**Écouter, ajuster, se faire comprendre — un laboratoire de prononciation FLE**

Conception : **Junior BOOTO Waba**. Version pilote du 17 novembre 2026.

**Statut : dispositif conçu, à expérimenter.** Aucun résultat d’élève ni effet mesuré n’est revendiqué.

Ce projet transforme une ressource de phonétique en parcours de communication : diagnostiquer une difficulté, s’entraîner avec des aides adaptées, transmettre un message, puis vérifier sur une situation nouvelle. L’élève conserve une première prise V0, une prise travaillée V1 et une prise de transfert V2.

Télécharger le fichier HTML puis l’ouvrir dans un navigateur compatible. La page GitHub affiche le code, elle ne lance pas l’application. L’accès au microphone dépend du navigateur et de ses autorisations ; un enregistreur habituel reste une alternative. Aucun modèle vocal n’est inclus, aucun score n’est calculé et aucune prise n’est envoyée à un serveur par cet outil.

## Public et parcours

Pilote proposé pour les Grades 4 et 5, niveau A1, notamment en contexte hispanophone, avec adaptations A2. Six séances de 45 minutes. Confirmer les besoins par diagnostic plutôt que déduire une difficulté de la langue première.

| Module | Tâche | Preuve |
| --- | --- | --- |
| Le message secret | Distinguer et transmettre rue, roue, bulle, boule | Perception et choix du partenaire |
| La phrase qui voyage | Transmettre moment, lieu et objet | Informations retrouvées |
| Une voix plusieurs intentions | Demander, confirmer, faire agir | Intention comprise dans son contexte |
| Le guide sonore | Inviter un nouvel élève | Script, prise V1 et transfert V2 |

L’écoute, la lecture, la parole et l’écriture sont évaluées séparément. Les seuils sont des critères de ce pilote, pas une certification CECRL.

## Démarche et compétences du concepteur

Analyse des besoins ; didactique de la prononciation ; conception de tâches ; différenciation ; création de ressources ; évaluation formative ; documentation et prototypage numérique. Les livrables montrent les décisions de conception. Les résultats d’utilisation restent à documenter.

## Vérification et limites

Documents rendus et contrôlés avant livraison. La syntaxe JavaScript a été vérifiée ; le test complet du navigateur n’a pas pu être mené dans l’environnement de production. Le code du studio doit être testé avec le microphone et le navigateur de l’établissement avant la séance ; la disponibilité d’un micro n’est pas garantie. Les comparaisons V0/V1/V2 décrivent des observations contextualisées et ne prouvent pas un effet causal.
