# Le musée des souvenirs inventés

**G3T3P1 · Grade 3 · Trimestre 3 · A1 en développement vers entrée A2**

**Question :** Comment raconter un événement dans un ordre compréhensible ?

**Mission :** Créer un récit passé à partir d’objets fabriqués par les élèves.

**Production :** Une exposition de trois souvenirs fictifs.

Durée : quatre séances de 45 minutes, intégrées aux unités du POI. Statut : conçu, à expérimenter.
