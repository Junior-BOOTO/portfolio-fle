# Annual French PYP projects 2027

**45 designed projects · Grades 1–5 · Nine per grade · Three per term**

Author: Junior BOOTO Waba. Status: designed prototypes, ready for a classroom pilot. No student results or demonstrated impact are claimed.

This collection follows the supplied POI, progressing from discovery-level French to consolidated A2. Each project includes four 45-minute sessions, original inquiry materials, differentiated support, an oral comprehension script and individual assessment of listening, reading, speaking and writing. It is a design proposal, not an IB endorsement or CEFR certification.

## Périmètre et sources

Les 27 heures de projet par grade font partie du volume annuel et ne remplacent pas les heures d’enseignement linguistique du POI. Les années scolaires et dates restent à fixer avec l’établissement. Les cibles annuelles d’écrit sont introduites progressivement ; les premières productions sont plus courtes.

Les scénarios sont fictifs ; les fiches ne redistribuent aucune page de manuel. Les scripts sont prêts à être lus ou enregistrés, sans fichiers MP3 fournis. Le numérique sert la réécoute, la révision et l’accès par le destinataire ; une alternative papier est prévue.

Références : POI de Junior BOOTO Waba, pages 2–41 ; Laafou, pages PDF 3–4 ; Ardouin, 4e édition, pages PDF 37–41 ; référentiel MINEFOP/PADESCE/CNFFDP, page PDF 28.
