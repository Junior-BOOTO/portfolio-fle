## Publication externe : état réel

**Les fichiers sont publiés sur GitHub, mais ils ne constituent pas encore une page hébergée sur le domaine professionnel** `junior-booto-fle.juniorbooto.chatgpt.site`. La connexion d'édition à ce site n'est pas disponible dans cette session, et aucun lien vers un hébergement public des démonstrations n'est annoncé comme actif.

Pour intégrer la version finale au site, conserver la structure suivante :

```text
booto-ai-lab/
  index.html
  demos/
    adaptive.html
    phonofle.html
```

Il faut transférer les fichiers HTML dans un même dossier public du site, ou reproduire les sections dans l'éditeur du site en actualisant les deux liens relatifs `demos/*.html`.

> La présence du code sur GitHub ne signifie pas une validation pédagogique en classe ni une mise en ligne sur un autre domaine.
